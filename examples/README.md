# Observable Output Backtrace — Sample Library

The `examples/` directory is an **observable-output backtrace sample library** for Fat-Based Metabolism (FBM).

## What This Is

- Illustrations of how to trace visible signs backward through mechanism layers to **food structure**
- Teaching material aligned with [STRUCTURE.md](../STRUCTURE.md) and species branch docs

## What This Is Not

- **Not** treatment advice
- **Not** diagnosis records
- **Not** product proof or effect guarantees
- **Not** a substitute for veterinary or medical care

Samples use minimal, anonymized context. They disclose no formulas, manufacturing parameters, customer data, or operational information.

## How to Use

1. Start from [\_template.md](./_template.md) for the fixed section structure.
2. Read species-relevant mechanism docs before extending samples.
3. Stop at **clinical boundary** when signs suggest emergency or diagnosed disease.
