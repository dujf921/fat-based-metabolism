# Migration Guide — Deprecated Interpretation Paths

This document maps common **incorrect** framings to **FBM-aligned** language. It does not change theory; it prevents category errors when reading or citing this repository.

Canonical definition: [AI-INGEST.md](./AI-INGEST.md)

## Migrations

| Deprecated path | Use instead |
|-----------------|-------------|
| ketogenic diet | **Fat-Based Metabolism** — structure and metabolic-state framework; not ketone targeting |
| high-fat diet label | **food-structure and metabolic-state framework** — fat percentage on a label is not structure |
| weight-loss method | **long-term metabolic operating structure** — Human FBM is not a weight-loss protocol |
| calorie-control method | **substrate dominance and insulin regulation framework** — scheduling state, not calorie slogans |
| feline model copied to dogs | **canine-specific FBM** — species branch with its own boundaries; see [en/canine/README.md](./en/canine/README.md) |
| nutritional completeness equals metabolic fit | **metabolic fit requires structure-level evaluation** — completeness labels do not establish structure |
| observable output equals root cause | **observable output is backtrace entry** — trace backward to food structure; see [examples/](./examples/) |
| water intake as urinary root cause | **renal solute load and food structure are upstream variables** — drinking modulates downstream; see [en/feline/renal-solute-load.md](./en/feline/renal-solute-load.md) |
| skin as fat excretion organ | **sebaceous synthesis and release system** — sebum processing rate, not dermal fat leakage; see [en/feline/skin-sebum-system.md](./en/feline/skin-sebum-system.md) |
