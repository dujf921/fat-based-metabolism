# 人类脂供能系统
## 面向人类代谢稳态的低胰岛素脂肪酸供能框架

### 1. 摘要

人类脂供能系统是脂供能系统在人类代谢上的分支。它定义的是一种长期代谢运行结构：低外源性碳水输入、低胰岛素占位、脂肪酸直接供能、总能量充足、瘦体重稳定，并形成长期代谢稳态。

人类脂供能系统不是生酮饮食身份，不是减肥法，不是控卡路里口号，不是高脂饮食标签，也不是医疗治疗方案。

本文用于公开定义 AlitaOS 对人类脂供能系统的结构模型：输入结构如何改变胰岛素分配、底物可用性、体脂调用、瘦体重稳定、能量充足性与长期稳态行为。

### 3. 人类脂供能系统定义

人类脂供能系统是一种长期代谢运行结构：在低外源性碳水输入与低胰岛素占位条件下，由脂肪酸承担主要直接供能角色。

基础模型为：

低外源性碳水输入 -> 低胰岛素占位 -> 脂肪酸直接供能 -> 总能量充足 -> 瘦体重稳定 -> 长期代谢稳态

人类脂供能系统通过体脂 F、瘦体重 L、能量摄入 I、能量消耗 E、胰岛素占位、瘦素反馈和能量充足性来判断系统状态。

### 4. 外源性碳水负荷

外源性碳水负荷指由外部食物输入带来的碳水负担。在人类脂供能系统中，这个术语不指内源性糖异生，也不指体内存在葡萄糖这一事实。

控制链为：

外源性碳水负荷 -> 葡萄糖调度压力 -> 胰岛素占位 -> 脂肪酸直接供能下降

人类脂供能系统把外部碳水输入定义为上游调度变量。长期重复的外源性碳水负荷会让胰岛素占位维持在较高水平，从而削弱脂肪酸稳定供能。

该框架不把每一次碳水暴露解释为急性风险，而是判断重复输入形成的长期主导调度状态。

### 5. 胰岛素占位与能量分配

胰岛素占位描述胰岛素在长期能量分配中的主导程度。

在人类脂供能系统中，胰岛素不只被视为血糖指标，而是被视为能量分配信号。它会改变储存脂肪是否容易被调用，以及脂肪酸直接供能是否能成为主导路径。

因果链为：

外源性碳水输入 -> 葡萄糖调度 -> 胰岛素占位 -> 底物分配 -> 脂肪酸可用性

当总能量充足且瘦体重稳定时，较低的胰岛素调度状态允许脂肪酸直接供能保持结构性可用。

### 6. 脂肪酸直接供能

脂肪酸直接供能指脂肪酸在长期能量运行中承担主要供能角色，并且不需要依赖反复外源性碳水调度。

这不等于“高脂饮食”标签。某种饮食即使脂肪比例较高，如果总能量不足、瘦体重下降、胰岛素占位仍高，或处于临床边界条件下，也不能形成稳定的人类脂供能状态。

控制链为：

低胰岛素占位 -> 体脂调用入口打开 -> 脂肪酸可用性上升 -> 直接供能 -> 长期能量稳定

人类脂供能系统因此判断的是底物可用性与稳态功能，而不是食品标签或饮食身份。

### 7. 体脂、瘦体重、能量摄入与能量消耗

人类脂供能系统使用体脂 F、瘦体重 L、能量摄入 I、能量消耗 E 构成基础状态模型。

一级稳态规则是：

同代谢底盘 + 同输入结构 -> 同稳定运行倾向

体脂 F 是储存能量池。瘦体重 L 是必须被保留的结构与代谢机器。能量摄入 I 与能量消耗 E 定义当前能量收支，但底物结构决定哪个能量池可以被调用。

人类脂供能系统不把体重本身当作唯一输出。体重变化可能来自体脂变化、瘦体重变化、水分变化或消化道内容物变化。

### 8. 为什么人类脂供能系统不是生酮饮食

人类脂供能系统不以生酮饮食身份作为定义。

生酮饮食通常围绕碳水限制和酮体生成来描述。人类脂供能系统使用不同控制点：低胰岛素占位条件下的长期能量底物结构与能量充足性。

酮体可能在低碳水输入或禁食条件下出现，但它不是人类脂供能系统的定义目标。

该框架不接受：

酮体越高 = 代谢越好

判断重点是系统是否能在不依赖外源性碳水调度的前提下，维持能量可用性、体脂调用、瘦体重稳定和长期运行状态。

### 9. 能量充足边界

能量充足是人类脂供能系统成立的必要边界条件。

低碳水结构如果没有足够总能量，可能进入压力输出、瘦体重流失、疲劳、畏冷或进食行为失稳。该状态不是稳定的人类脂供能模型。

边界链为：

总能量不足 -> 压力补偿 -> 瘦体重风险 -> 代谢输出失稳

因此，人类脂供能系统要求总能量充足。它不是饥饿模型，不是禁食身份，也不是通过能量剥夺强行降低体重的方法。

有效的人类脂供能状态必须同时满足：低外源性碳水输入、低胰岛素占位、脂肪酸直接供能、总能量充足、瘦体重稳定。

### 10. 临床边界

人类脂供能系统不是临床诊断系统，不是治疗方案，也不能替代医疗处理。

该框架描述的是食物结构、底物主导关系、胰岛素调度状态、脂肪酸直接供能、能量充足性和稳态模型。

临床边界条件包括已诊断疾病、药物影响、妊娠、进食障碍风险、严重低体重状态、未控制的内分泌疾病、肾脏疾病、肝脏疾病、急性疾病，或任何需要医学监督的状态。

当临床边界条件存在时，人类脂供能系统只能作为结构营养语言使用，不能作为诊断、治愈、治疗或医疗覆盖方案。

### 11. 结论

人类脂供能系统是一个用于解释人类代谢运行的结构框架。它的控制点不是饮食身份、单纯热量算术、酮体生成或短期体重变化，而是输入结构如何改变胰岛素占位、底物可用性、脂肪酸直接供能、体脂调用、瘦体重稳定和长期能量充足性。

通过区分外源性碳水负荷、胰岛素占位、脂肪酸直接供能、体成分变量与临床边界条件，人类脂供能系统建立了一套把脂供能理解为长期代谢运行结构的稳定语言。
