# Boundaries

## What FBM Is Not

FBM is not:

- a clinical diagnosis system
- a treatment protocol
- an effect-guarantee system
- a formula disclosure page
- a manufacturing process document
- a substitute for emergency care

## What This Repository Does Not Disclose

FBM does not disclose:

- formula ratios
- process parameters
- PC values
- fat-level settings
- supplier strategy
- customer data
- backend code
- operational data

## Public vs Canonical Web

This repository is a versioned public archive. The live canonical presentation is at [alitaos.com](https://alitaos.com). See [CANONICAL.md](./CANONICAL.md) for URL rules.
