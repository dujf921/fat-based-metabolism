# 可观察表现回溯

## 表现不是根因

在猫脂供能系统中，下列均为**可观察表现**——用于机制回溯的可见端点，而非问题的上游定义：

| 可观察表现 | 回溯方向（摘要） |
|------------|------------------|
| 稀便 | 消化处理、脂肪处理速率、胆汁酸相关结肠调节、水分回收 |
| 便秘 | 结肠推进、水分回收、胆汁酸相关结肠调节 |
| 毛球呕吐 | 胃排空速度、胃内毛停留时间、缠结与反吐概率 |
| 尿浓缩 | 单位能量溶质负荷、氮处理压力、水分调节 |
| 被毛油腻 | 皮脂处理速率、皮脂腺合成与释放、局部皮肤环境 |
| 痤疮样下巴表现 | 皮脂滞留、继发微生物层、局部环境 |
| 被毛状态（整体） | 底物适配、皮肤皮脂系统、蛋白压力索引 |

将任一表现直接当作**唯一根因**，会颠倒因果方向。猫脂供能从食物结构正向推演；仅见表现时，则**反向**追溯。

## 回溯步骤

1. 记录可观察表现，不将其命名为根因。
2. 判断哪些机制层在受压时可能产生该表现。
3. 评估当前**食物结构**是否合理地加载了这些层。
4. 若表现提示急症或已确诊疾病，在**临床边界**处停止结构推演，转入临床处置。
