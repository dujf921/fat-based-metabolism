# 猫脂供能系统

猫脂供能系统是脂供能系统在猫这一强制肉食动物物种上的分支。它判断的不是市场品类、配料表或孤立营养素比例，而是食物结构进入猫体内后形成的长期代谢运行状态。

正式中文定义源（网站）：https://alitaos.com/zh/fat-based-metabolism/feline
