# 脂供能 Fat-Based Metabolism

## 1. 定义

脂供能，是指以脂肪作为主要能量供给结构的代谢模型。

它不是生酮饮食，也不是单纯低碳水饮食。

脂供能的核心判定对象不是“酮体高不高”，而是：

- 脂肪是否成为主要能量来源
- 胰岛素是否长期处于低占位状态
- 能量供给是否由脂肪系统稳定承接

## 2. 与生酮的区别

生酮关注的是酮体结果。

脂供能关注的是能量来源结构。

因此：

- 酮体升高，不等于脂供能成立
- 酮体不高，也不等于脂供能不成立
- 脂肪氧化可以在低酮体状态下长期发生

## 3. 核心机制

脂供能模型包含三个基础机制：

1. 外源性碳水下降
2. 胰岛素占位下降
3. 脂肪供能比例上升

当这三个条件同时成立，身体才会从糖主导供能切换到脂肪主导供能。

## 4. 适用范围

本模型用于解释：

- 人类低碳水 / 无外源性碳水饮食
- 猫狗高脂低溶质负荷食物结构
- 脂肪作为主供能来源时的代谢变化

## 5. 非本模型内容

本模型不讨论：

- 传统热量节食模型
- 高碳水饮食优化
- 单纯酮体数值追踪
- 主流生酮饮食话术
