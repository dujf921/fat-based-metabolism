# Observable Output Backtrace

## Outputs Are Not Root Causes

In Feline FBM, the following are **observable outputs**—visible endpoints for mechanism backtrace, not upstream definitions of the problem:

| Observable output | Backtrace direction (summary) |
|---------------------|-------------------------------|
| Loose stool | Digestive handling, fat processing rate, bile-acid-related colonic regulation, water recovery |
| Constipation | Colonic propulsion, water recovery, bile-acid-related colonic regulation |
| Hairball vomiting | Gastric emptying speed, hair residence time, entanglement and regurgitation probability |
| Urinary concentration | Solute load per unit energy, nitrogen processing pressure, water modulation |
| Greasy coat | Sebum processing rate, sebaceous synthesis and release, local skin environment |
| Acne-like chin presentation | Sebum retention, secondary microbial layer, local environment |
| Coat condition (general) | Substrate alignment, skin-sebum system, protein pressure indexing |

Treating any single output as **the** cause reverses causal direction. FBM starts from food structure and traces forward; when only outputs are visible, it traces **backward**.

## Backtrace Method

1. Record the observable output without naming it the root cause.
2. Map which mechanism layers could produce that output under stress.
3. Evaluate whether current **food structure** plausibly loads those layers.
4. Stop at **clinical boundary** if signs suggest emergency or diagnosed disease.
